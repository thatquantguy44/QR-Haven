# Research Project Template

## Hypothesis

State the investment or engineering hypothesis in one falsifiable paragraph.

## Literature Review

Summarize papers, practitioner notes, and known limitations.

## Data

Define source, coverage, frequency, survivorship treatment, corporate actions, missingness, and
point-in-time assumptions.

## Methodology

Describe feature construction, model design, portfolio construction, costs, risk controls, and
validation windows.

## Implementation

Link reusable modules in `src/qr_haven`, notebooks, configs, and scripts.

## Results

Report IC, rank IC, Sharpe, Sortino, turnover, drawdown, capacity, slippage, and statistical
robustness where relevant.

## Limitations

Document model risk, data risk, capacity limits, instability, and implementation gaps.

## Future Work

List follow-up tests, productionization steps, and terminal integration opportunities.
